# Pokemon Match

This project is a browser-based Pokémon-inspired memory-matching game. Players flip cards to reveal images and try to find matching pairs.
The application was created using HTML, CSS, and JavaScript and runs entirely in the browser.

### This project demonstrates:
1. Event handling in JavaScript
2. DOM manipulation
3. Basic game logic
4. Dynamic webpage updates

### How to Run

1. Download or clone the repository: git clone https://github.com/Jasminaryee/pokemon-match
2. Open index.html in a web browser.


### Future Improvements/Bugs
1. User not constrained to 2 moves at a time
2. Fully implemented medium difficulty
3. Mobile layout refinements
